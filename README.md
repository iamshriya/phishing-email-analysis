Phishing Email Analysis

Project Overview

This beginner-level cybersecurity project analyses simulated email examples to identify potential phishing indicators and document preliminary risk assessments.

Objectives

- Identify suspicious sender domains, URLs, urgency, and other red flags.
- Classify email examples by their apparent risk.
- Review simulated email-header authentication results.
- Record evidence and document investigation findings.
- Practise clear, evidence-based security reporting.

Tools Used

- Microsoft Excel — email analysis and evidence logging
- Microsoft Word — incident investigation report
- GitHub — project documentation and version control

Project Contents

- "Phishing-Email-Analysis.xlsx.xlsx" — workbook containing the phishing analysis, simulated header analysis, and evidence log.
- "PH-004_Incident-Investigation-Report.docx" — preliminary investigation report based on simulated email-header data.

Investigation Process

1. Reviewed the available simulated email information.
2. Recorded suspicious indicators, including unusual domains, links, urgency, and unexpected attachments.
3. Assessed email-header authentication results in a fictional training scenario.
4. Documented observations, evidence, limitations, and recommended follow-up actions.

Key Findings

The training examples demonstrate that suspicious domains, pressure tactics, unexpected attachments, authentication failures, and mismatched sender information may warrant further investigation.

These indicators do not independently prove that an email is malicious. Legitimate configuration issues can also cause authentication failures.

Limitations

All email examples and header results in this project are simulated for educational purposes. No real email, sender infrastructure, or security incident was investigated. The findings are preliminary and must not be interpreted as confirmation of a real phishing attack.
